# Ransomware diagnosis

## Objetivo
Examinar si se trata de un caso de ransomware mediante la observación de su comportamiento

## Herramientas
<ul>
 <li>VirusTotal</li>
 </ul> 
 
## Hallazgos y análisis

<ul>
 <li>Se descubrió que la aplicación como tal uso powershell </li>
 <li>Se identifico que el malware hizo comunicación externa para descargar una aplicación</li>
  <li>Se observo que la aplicación descargada fue la responsable de haber cifrado los datos</li>
 </ul> 

## Conclusión

Se evidencio que por las características del caso se trata del malware conocido como ransomware 
ya que no permite poder acceder a los datos del usuario.
